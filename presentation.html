Project Profile — Existing System

Existing System

🔴 Current Manual Process

  • Registrations via Google Forms — no validation, duplicates possible
  • Team formation via WhatsApp and manual email coordination
  • Problem statements as PDF attachments — no version control
  • Submissions via email — unorganized, deadline misses common
  • Judging on Excel sheets — no standardized rubric enforcement
  • Announcements via WhatsApp broadcast — not guaranteed delivery
  • Certificates issued manually — time-consuming and error-prone
  • No central dashboard — coordinators juggle 5+ tools simultaneously

⚠️ Limitations & Drawbacks

  • High manual effort — prone to human error and inconsistency
  • No role-based access — data accessible to unauthorized persons
  • Zero real-time visibility — no live participation metrics
  • Scattered data across forms, sheets, emails — no single source of truth
  • Difficult to scale — every hackathon restarts the process from scratch
  • No automated notification or reminder system
  • Judges have no structured feedback mechanism
  • No audit trail — no history of past hackathons
Project Profile — Proposed System

Proposed System

✅ CHMS Capabilities

  • Centralized web platform accessible from any device via browser
  • RBAC with 4 roles: Student, Coordinator, Judge, Admin
  • Team formation with unique join codes & email invitations
  • Structured project submission portal with repo URL & demo links
  • Standardized evaluation rubrics with per-criterion scoring
  • Automated email notifications via Gmail SMTP
  • Dynamic certificate generation with printable templates
  • Admin dashboard with platform-wide analytics

🎯 Objectives Achieved

  • Eliminate manual coordination — one platform for all stakeholders
  • End-to-end lifecycle: Draft → Upcoming → Active → Ended
  • Real-time notifications (Global, Team, Personal)
  • Dual-theme UI (Tech-Noir Dark & Academic Light)
  • RESTful API — easily extendable and scalable
  • Data integrity via Pydantic schemas & SQLAlchemy ORM
  • Deployment-ready: Vercel + Render/Railway
  • Reusable across multiple hackathon events without reconfiguration
Project Profile — Tools & Technologies

Development Tools & Technology Stack

⚛️
React 18 + TypeScript
SPA with hooks, Context API, and strong typing via Vite 8 + React Router
⚡
Vite 8
Lightning-fast dev server and build tool with HMR and optimized bundling
🎨
Tailwind CSS v3.4
Utility-first CSS with custom Tech-Noir glassmorphism design system tokens
🐍
FastAPI (Python 3.13)
Async REST API with automatic OpenAPI docs at /docs, Pydantic v2 schemas
🗃️
SQLAlchemy 2.0 + Alembic
ORM for database models; Alembic for version-controlled schema migrations
🐘
PostgreSQL / SQLite
SQLite for local dev; Supabase PostgreSQL for production deployment
🔐
JWT + Passlib / Bcrypt
Stateless authentication with bcrypt hashing and role-based token claims
📧
Gmail SMTP (smtplib)
Automated HTML email engine for team invitations and announcements
🚀
Vercel + Render
CI/CD deployment: Vercel for frontend, Render/Railway for backend API
